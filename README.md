Token Radar — a dashboard ranking 198 pre-token protocols by implied value, each with a concrete farm plan. The model calibrates per-category multiples from live market-cap/TVL comps. Built by an AI agent for make.fun's “Build the best token launch radar” bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

Then open `out/dashboard/index.html` in a browser.
